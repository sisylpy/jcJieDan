# boss-mini 销售分析模块边界

- 本页面是老版老板小程序的只读销售经营分析，不负责下单、改价、采购或库存写入。
- 数据层级固定为配送商品大类 → 小类 → 商品 → 使用客户；移动端商品客户详情使用底部面板。
- 页面只能调用 `lib/apiDistributer.js` 中的 Owner 销售分析请求，不得传入配送商 ID，也不得直连桌面 Token 接口。
- 服务端统计只读取 `nx_department_order_history`，数量和加权平均价始终按交易单位分组。
- 管理员权限同时由小程序入口和服务端校验；隐藏入口不能替代服务端鉴权。
- 日期入口与售后管理保持一致：顶部单行展示范围，点击进入 `subPackage-charts/pages/sel/date/date`；返回后刷新统计，但销售分析单次范围仍不得超过 90 天。
- 具体商品卡片和客户分布面板必须显示商品图片；统一按配送大图、配送普通图、平台父类图、平台商品大图、平台商品普通图回退，不能直接拼接 `api/` 地址。
- 详细统计口径、接口和回归记录见 [变更日志](../../../../docs/销售分析与客户商品金额排序-变更日志.md)。
