# boss-mini 采购分析商品展示边界

## 页面职责

- `purGoodsFenxi` 展示选定日期内的采购员、供应商、采购次数、采购金额和单价波动分析。
- 商品排行继续使用 `getNxPurGoodsStatisticsForDis` 的既有统计结果；页面只做展示排序结果，不在客户端重新计算采购金额、次数或波动率。
- 点击排行商品进入 `goodsFenxiPurchase` 查看该商品的采购批次和入库明细。

## 商品图片

- 排行卡片和商品明细首屏统一优先使用 `nxDgGoodsFileLarge`，其次使用 `nxDgGoodsFile`，再使用历史父类图片 `nxDgNxFatherImg` 和平台商品图；所有来源都没有时使用本地占位图。
- 相对图片路径使用当前环境 `config.server` 拼接，完整网络地址保持原样，禁止写死生产域名。
- 图片和规格只用于帮助识别商品，不参与采购统计、筛选、跳转参数或采购批次判断。

## 修改要求

后续修改采购分析商品卡片时，必须同时检查：

1. 三组排行都能显示商品图片；
2. 缺图商品有稳定占位；
3. 点击商品仍携带完整商品对象和商品 ID 进入采购明细；
4. 采购明细首屏图片与当前商品一致；
5. `tests/purchaseAnalysis.product-image.test.mjs` 与对应变更日志同步更新。
