# 采购员列表、详情与任务入口

## 页面职责

- `purchaserList` 展示真实人员、当前任务、本期采购记录与按统一规则归属的采购金额。
- `purchaserDetail` 默认展示不受历史日期影响的当前任务；“采购记录”页签按所选日期展示真实批次和批次外自采。
- 页面不展示未验收的损耗、毛利、资金异常，也不创建收货、入库或付款操作。

## 正式去向

- 未成批采购任务：精彩订货 `pkgPurchase/pages/purchaseTasks/purchaseTasks`。
- 未分享的真实批次：精彩订货 `pkgPurchase/pages/txs/purPrepareBatch/purPrepareBatch`。
- 待采购方核对供货信息：精彩订货 `pkgPurchase/pages/txs/disOrderBatch/disOrderBatch`，携带精确 `batchId`。
- 等待供应商或只读任务：Boss 真实采购批次详情，不提供假处理按钮。

Boss 只使用后端返回的租户内采购员、采购方精彩订货身份和动作码。找不到对应采购身份时只提示由对应采购员登录精彩订货处理，不降级到泛首页或另一套采购流程。

## 验收要点

1. 列表同时能看到有任务人员与本期无记录的正常采购员。
2. 详情默认显示当前任务；改变历史日期只影响采购记录和金额。
3. 从精彩订货返回后自动重读任务，处理完成的任务按后端状态推进或消失。
4. 等待供应商的任务不显示为老板待办；多商品批次只计一个任务。
5. 请求失败显示错误和重试，不显示为零任务。
