# 采购商品入库并生成溯源报告接口文档

## 接口概述

该接口用于保存采购商品入库信息，并同时上传溯源报告文件（支持图片或PDF格式）。接口会将采购商品、库存批次和溯源报告三者关联起来，实现完整的溯源功能。

## 接口信息

- **接口路径**: `/api/nxdistributerpurchasegoods/disSavePurGoodsSaveStockWithTraceReport`
- **请求方式**: `POST`
- **Content-Type**: `multipart/form-data`（因为需要上传文件）

## 请求参数

### 采购商品参数（必填）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| nxDpgDisGoodsId | String | 是 | 配送商商品ID |
| nxDpgDistributerId | String | 是 | 配送商ID |
| nxDpgQuantity | String | 是 | 采购数量 |
| nxDpgBuyPrice | String | 是 | 采购单价 |
| nxDpgBuySubtotal | String | 是 | 采购小计 |

### 采购商品参数（可选）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| nxDpgDisGoodsFatherId | String | 否 | 商品父级ID |
| nxDpgDisGoodsGrandId | String | 否 | 商品爷爷级ID |
| nxDpgExpectPrice | String | 否 | 期望价格（建议零售价） |
| nxDpgPurUserId | String | 否 | 采购员用户ID |
| nxDpgInputType | String | 否 | 输入类型 |
| nxDpgPurchaseType | String | 否 | 采购类型 |
| nxDpgStandard | String | 否 | 采购规格 |
| nxDgssPriceCarton | String | 否 | 外包装单价（有外包装的商品） |
| nxDgssSellingPriceCarton | String | 否 | 外包装建议零售价（有外包装的商品） |
| nxDistributerGoodsShelfGoodsId | String | 否 | 货架商品ID |

### 溯源报告参数（可选）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| traceReportFile | MultipartFile | 否 | 溯源报告文件（图片或PDF） |
| nxTrSupplierId | String | 否 | 供应商ID |
| nxTrSupplierName | String | 否 | 供应商名称 |
| nxTrSupplierContact | String | 否 | 供应商联系方式 |
| nxTrValidStartDate | String | 否 | 报告有效期开始日期（格式：yyyy-MM-dd，默认为今天） |
| nxTrValidEndDate | String | 否 | 报告有效期结束日期（格式：yyyy-MM-dd） |
| nxTrRemark | String | 否 | 备注说明 |

### 文件上传说明

- **文件字段名**: `traceReportFile`
- **支持格式**: 
  - 图片：jpg, jpeg, png, gif, bmp
  - 文档：pdf
- **文件大小**: 建议不超过 10MB
- **文件存储**: 文件会上传到服务器的 `traceReports/` 目录下，保存原始文件名

## 业务流程说明

1. **保存采购商品**: 首先调用内部方法保存采购商品信息
2. **保存库存批次**: 根据采购商品信息创建库存批次记录
3. **上传溯源报告文件**: 如果有上传文件，保存到服务器 `traceReports/` 目录
4. **创建溯源报告记录**: 保存溯源报告信息到数据库
5. **关联溯源报告**: 将溯源报告ID关联到采购商品和库存批次

## 注意事项

1. **文件格式限制**: 仅支持图片（jpg/jpeg/png/gif/bmp）和PDF格式，其他格式会返回错误
2. **文件可选**: `traceReportFile` 参数为可选，如果不传文件，接口仍会正常保存采购商品和库存，只是不会创建溯源报告
3. **日期格式**: 日期参数使用 `yyyy-MM-dd` 格式（例如：2025-01-01）
4. **文件路径**: 文件保存后的路径格式为 `traceReports/原始文件名`，前端访问时需要拼接服务器域名
5. **关联关系**: 
   - 一个采购商品对应一个溯源报告（通过 `nx_DPG_trace_report_id` 字段关联）
   - 一个库存批次对应一个溯源报告（通过 `nx_dgss_trace_report_id` 字段关联）
   - 如果多个采购商品需要共享同一个溯源报告，需要先创建溯源报告，然后在其他接口中关联

## 错误处理

常见错误情况：

1. **文件格式不支持**: 
   - 错误信息：`不支持的文件格式，仅支持图片（jpg/png/gif/bmp）和PDF文件`
   - 解决方法：检查文件扩展名，确保为支持的格式

2. **文件上传失败**:
   - 错误信息：`上传溯源报告文件失败: ...`
   - 解决方法：检查文件大小、服务器磁盘空间和权限

3. **参数缺失**:
   - 错误信息：`保存失败，无法获取采购商品ID`
   - 解决方法：确保必填参数都已传递

## 相关接口

- **查看溯源报告**: 可通过溯源报告ID查询报告详情（需要单独实现查询接口）
- **更新溯源报告**: 可通过更新接口修改溯源报告信息（需要单独实现更新接口）
- **无溯源报告入库**: 如果不需要溯源报告，可以使用 `/disSavePurGoodsSaveStockSunHola` 接口
