# 老版老板小程序：采购分析商品展示变更日志

## 2026-09-02：排行卡片和采购明细增加商品图片

### 修改原因

- 原采购分析虽然个别列表模板包含小图判断，但视觉上仍是普通文字行，商品识别不够直观；商品采购明细首屏也没有显示当前商品图片。

### 修改内容

- 新增统一的商品图片投影工具，依次处理配送商品大图、普通图、父类历史图和本地占位图，并兼容相对路径与完整网络地址。
- 单价波动、采购次数、采购金额三组排行统一改为商品卡片：左侧商品图，中间名称和规格，右侧突出核心指标。
- 商品采购明细页在日期栏下增加商品图片、名称和规格概览；原图表、采购批次、展开详情和日期逻辑不变。
- 统计接口和 Server SQL 原本已经返回 `nxDgGoodsFile`、`nxDgGoodsFileLarge`，本次没有修改采购统计口径或服务端查询。

### 回归保护

- `purchaseAnalysis.product-image.test.mjs` 锁定图片优先级、完整 URL、缺图占位、三组排行图片和明细首屏图片。

### 发布说明

- 本次只需更新 boss-mini 小程序包；采购分析部分不要求数据库 migration 或 Server 接口变更。

### 本次验证

- `purchaseAnalysis.product-image.test.mjs` 通过。
- 智能备货三组回归、销售分析三组回归继续通过；页面 JSON、ES module 语法和相关 diff 检查通过。

## 2026-09-02：补齐采购排行父类图片字段

- 本轮在采购次数、采购金额、单价波动三条 Top 商品查询中都显式返回父类图片，并继续由统一图片工具做路径拼接和缺图兜底。
- 该修正只增加展示字段，不改变采购次数、金额、波动率、日期或供应商统计口径。

### 回归保护

- boss-mini 图片测试增加父类图片和平台商品图片路径用例。
- Server `PurchaseStatisticsQueryContractTest` 锁定三条 Top 商品查询都必须返回 `nxDgNxFatherImg`。
