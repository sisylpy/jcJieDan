# 多员工共用标签打印机实现方案

## 背景

在实际使用场景中，多名员工需要共用同一台标签打印机和出库单打印机。由于蓝牙打印机通常不支持多设备同时连接，如果前一个员工打印完成后不断开连接，后续员工将无法连接打印机。

## 解决方案

**核心思路**：每次打印完成后，主动断开蓝牙连接，释放打印机资源，供下一个员工使用。

## 实现细节

### 1. 打印机存储分离

为了避免标签打印机和出库单打印机之间的冲突，我们实现了完全分离的存储机制：

#### 标签打印机
- **缓存位置**：`wx.getStorageSync('bleDeviceInfo')`
- **页面变量**：`this.labelPrinterInfo`（页面级变量，不写入全局）
- **相关文件**：`pages/stock/index/index.js`

#### 出库单打印机
- **缓存位置**：`wx.getStorageSync('receiptPrinterInfo')`
- **页面变量**：`this.data.deviceId`, `this.data.writeServiceId`, `this.data.writeCharaterId`
- **相关文件**：`subPackage/pages/prepare/printWeightOrders/printWeightOrders.js`

### 2. 打印完成后自动断开连接

#### 标签打印断开逻辑

**文件**：`pages/stock/index/index.js`

**位置**：`printLabels()` 方法中的 `printLabelsSequentially()` 函数

**实现**：

```javascript
if (orderIndex >= orderArray.length) {

    that._closeLabelPrinterConnection();

  return;
}
```

**断开连接方法**：`_closeLabelPrinterConnection()`
```javascript
_closeLabelPrinterConnection() {
  var that = this;
  // 使用页面级变量 labelPrinterInfo
  var labelPrinterInfo = that.labelPrinterInfo;
  if (labelPrinterInfo && labelPrinterInfo.deviceId) {
    console.log('📴 准备断开标签打印机连接，deviceId:', labelPrinterInfo.deviceId);
    wx.closeBLEConnection({
      deviceId: labelPrinterInfo.deviceId,
      success: function(res) {
        console.log('✅ 标签打印机连接已断开');
        // 清除页面级变量中的连接状态
        if (that.labelPrinterInfo) {
          that.labelPrinterInfo.isConnected = false;
        }
      },
      fail: function(err) {
        console.log('⚠️ 断开标签打印机连接失败:', err);
        // 即使断开失败，也清除连接状态标记
        if (that.labelPrinterInfo) {
          that.labelPrinterInfo.isConnected = false;
        }
      }
    });
  } else {
    console.log('⚠️ 标签打印机信息不存在，无需断开连接');
  }
}
```

```javascript
_closeBluetoothConnection() {
  var that = this;
  if (this.data.deviceId) {
    console.log('📴 准备断开出库单打印机连接，deviceId:', this.data.deviceId);
    wx.closeBLEConnection({
      deviceId: this.data.deviceId,

        console.log('✅ 出库单打印机连接已断开');

        that.setData({
          isBluetoothConnected: false
        });
      },
      fail: function(err) {
        console.log('⚠️ 断开出库单打印机连接失败:', err);
        // 即使断开失败，也清除连接状态标记
        that.setData({
          isBluetoothConnected: false
        });
      }
    });
  } else {
    console.log('⚠️ 出库单打印机信息不存在，无需断开连接');
  }
}
```

### 3. 延迟断开的原因

在打印完成后，我们延迟 500ms 再断开连接，原因如下：

1. **确保数据完整发送**：蓝牙数据传输需要时间，延迟可以确保所有数据包都已发送到打印机
2. **打印机处理时间**：打印机接收到数据后需要时间处理和执行打印命令
3. **避免过早断开**：如果立即断开，可能导致最后的数据包丢失或打印不完整

## 工作流程

### 标签打印流程

1. 用户点击"打印标签"按钮
2. 从缓存读取标签打印机信息 (`bleDeviceInfo`)
3. 连接蓝牙打印机
4. 发送打印数据
5. 所有标签打印完成
6. 延迟 500ms（确保打印机处理完数据）
7. **自动断开蓝牙连接** ← 关键步骤
8. 下一个员工可以连接打印机

### 出库单打印流程

1. 用户进入打印页面
2. 从缓存读取出库单打印机信息 (`receiptPrinterInfo`)
3. 连接蓝牙打印机
4. 发送打印数据
5. 所有打印数据发送完成
6. 延迟 500ms（确保打印机处理完数据）
7. **自动断开蓝牙连接** ← 关键步骤
8. 下一个员工可以连接打印机

## 优势

1. **无需手动操作**：打印完成后自动断开，员工无需手动操作
2. **资源自动释放**：打印机资源自动释放，下一个员工可以立即使用
3. **支持多用户**：即使打印机不支持多连接，多个员工也可以轮流使用
4. **打印任务交错可接受**：多个员工同时打印时，打印内容会交错，但这是可接受的
5. **完整的日志记录**：便于调试和追踪问题

## 注意事项

1. **延迟时间**：500ms 的延迟是经过测试的，如果发现打印不完整，可以适当增加延迟时间
2. **连接失败处理**：如果断开连接失败，代码会清除连接状态标记，确保下次可以重新连接
3. **打印机兼容性**：此方案适用于所有蓝牙打印机，无论是否支持多连接
4. **打印任务交错**：多个员工同时打印时，打印内容会交错打印，这是正常现象

## 测试建议

1. **单用户测试**：单个员工打印完成后，检查连接是否已断开
2. **多用户测试**：多个员工依次打印，验证每个员工都能正常连接和打印
3. **并发测试**：多个员工同时点击打印，验证系统行为
4. **日志检查**：查看控制台日志，确认断开连接的流程正常
