# 供应方正式入口说明

## 内部协作配送商

双方都有 NX 配送商和老板端身份，可按方向互相采购、供货。

正式调用链：

1. 管理首页进入 `offerNxDistributerList`。
2. 页面按供货方向分享 `inviteOfferDis`。
3. 已有配送商账号直接接受；新用户先由 `inviteLogin` 创建真实 NX 配送商身份。
4. 最终统一调用 `nxdistributernxdistributer/saveBusiness`，写入 `nx_distributer_nx_distributer`，并沿用原有方向 block、商品共享、订单和账单能力。

不得在其他页面复制邀请表单，不得写入 `nx_jrdh_supplier`。

## 外部供应商

外部供应商没有老板端配送商身份，通过精彩订货供货。

正式调用链：

1. Boss 在正式采购流程创建真实采购批次，并打开精彩订货 `prepareBatch` / `disOrderBatch` 批次页面。
2. 采购方从批次页面直接使用微信分享给供货商好友；分享参数必须包含服务端可复核的 `batchId`。
3. 供货商打开分享批次。未注册时由该批次页采集微信资料并调用 `jrdhSellerRegisterWithFile`；服务端重新读取批次所属配送商和采购人，复用已有精彩订货账号或新建账号，并建立当前配送商下的 `nx_jrdh_supplier` 关系。
4. 注册/登录完成后，供货商在精彩订货批次和卖方协同页面接单、报价、填重量与发货。

Boss “外部供应商”页面只展示和管理已经由真实批次分享建立的关系，不预建供应商，不提供独立邀请按钮。
