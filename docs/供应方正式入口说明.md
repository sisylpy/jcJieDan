# 供应方正式入口说明

## 内部协作配送商

双方都有 NX 配送商和老板端身份，可按方向互相采购、供货。

正式调用链：

1. 管理首页或采购管理进入 `offerNxDistributerList`。
2. 页面按供货方向分享 `inviteOfferDis`。
3. 已有配送商账号直接接受；新用户先由 `inviteLogin` 创建真实 NX 配送商身份。
4. 最终统一调用 `nxdistributernxdistributer/saveBusiness`，写入 `nx_distributer_nx_distributer`，并沿用原有方向 block、商品共享、订单和账单能力。

不得在其他页面复制邀请表单，不得写入 `nx_jrdh_supplier`。

## 外部供应商

外部供应商没有老板端配送商身份，通过精彩订货供货。

正式调用链：

1. Boss `supplierCollaboration` 创建或为既有 `nx_jrdh_supplier` 关系重新生成安全邀请。
2. 分享目标固定为精彩订货 `supplierInvitation?token=...`。
3. 精彩订货校验令牌、接受并激活关系。
4. 精彩订货卖方协同页负责接单、备货和发货。

商品的未激活外部供应商不再直跳旧 `pages/jinriListWithLogin`，而是回到 Boss 正式邀请页并携带现有关系 ID，避免重复建关系。

## 已废弃，不得据此开发

- 精彩订货买方侧重复的 `supplierCollaboration` 邀请页面。
- 精彩订货旧 `inviteSeller` / `sellerRegister` 分享注册链。
