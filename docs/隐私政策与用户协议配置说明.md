# 微信小程序隐私政策与用户协议配置说明

针对《微信小程序平台运营规范常见拒绝情形3.4》的整改说明。

## 一、已完成的代码改动

### 1. 新增页面
- **用户服务协议**：`pages/agreement/userAgreement/userAgreement`
- **隐私政策**：`pages/agreement/privacyPolicy/privacyPolicy`

### 2. 隐私授权流程
- **邀请码页面**：首次进入时如未同意隐私协议，会弹出授权弹窗，用户需点击「同意并继续」后继续使用
- **登录/注册页面**：增加「我已阅读并同意《用户服务协议》和《隐私政策》」勾选，用户必须勾选后才能注册
- 使用微信官方 `agreePrivacyAuthorization` 按钮完成隐私协议同步

### 3. app.json 配置
- 已添加 `"__usePrivacyCheck__": true` 启用隐私检查

## 二、小程序管理后台必须配置（重要）

在提交审核前，请务必完成以下配置：

### 1. 用户隐私保护指引

**路径**：小程序管理后台 → 设置 → 服务内容声明 → 用户隐私保护指引

或**提审时**：管理 → 版本管理 → 提交代码审核 → 信息填写页面的隐私指引

**填写说明**：根据你实际使用的接口，在指引中声明收集的信息类型，例如：

| 接口/组件 | 说明 | 建议勾选 |
|----------|------|----------|
| 获取用户信息（头像、昵称） | 用于完善会员资料 | ✓ |
| 选择位置 | 用于配送范围、路线规划 | ✓ |
| 实时定位 | 用于配送路线、地图展示 | ✓ |
| 后台定位 | 用于配送中位置更新 | ✓ |

**注意**：未在指引中声明的接口将被平台禁用。你当前 `app.json` 中已声明：
- `chooseLocation`
- `onLocationChange`
- `startLocationUpdate`
- `startLocationUpdateBackground`

### 2. 隐私保护指引内容

在指引中需明确说明：
- 收集哪些信息类型
- 收集目的
- 使用方式
- 存储与保护措施

可参考 `pages/agreement/privacyPolicy/privacyPolicy.wxml` 中的文案。

## 三、审核注意事项

1. **提审时**：在「隐私协议」相关选项中勾选「已配置用户隐私保护指引」
2. **不要勾选**「未采集隐私」—— 本小程序会收集用户信息
3. 配置完成后约 **5 分钟** 生效

## 四、常见错误

- `api scope is not declared in the privacy agreement`：未在后台声明该隐私接口，需补充声明
- `appid privacy api banned`：提审时勾选了「未采集隐私」或未声明隐私协议

## 五、验证

1. 清除小程序缓存后重新进入
2. 首次进入应看到隐私授权弹窗
3. 登录页需勾选协议后才能注册
4. 点击《用户服务协议》《隐私政策》可正常跳转
