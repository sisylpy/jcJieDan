# 老版老板小程序：智能备货迁移变更日志

## 2026-09-02：完整迁移桌面端智能备货

### 页面与交互

- 设置页“经营分析”新增“智能备货”入口，只对配送商老板账号显示。
- 新增移动端智能备货主页，包含今天、明天、未来 7 天、自定义日期，A/B 等级筛选，大类筛选，商品搜索，预估数量，可信度，需求客户，库存数量，采购状态和人工添加采购。
- 商品按 A 级优先、B 级其次、可信度降序排列；只展示服务端明确返回的 A/B 级，客户端不计算 Policy，也不展示 C/abstain。
- 预测依据可以在商品卡片中展开，保留服务端支持理由、风险理由和数量说明。
- 客户选择从主页面拆成独立页面，支持搜索、大量客户列表和“全部客户”；首次进入继续与桌面端一致，默认选中有历史记录的第一个客户。

### 日期与预测口径

- 页面先读取 catalog，以服务端 `forecastDate` 作为“今天”，不使用手机本地日期，也不使用按 02:30 切换的 `businessDate`。
- 自定义范围只能选择服务器今天及未来日期，单次最多 31 天，并受 `maxForecastDate` 限制。
- 预测请求固定使用稳定基线 `V8_REPLENISHMENT_STATE` 和 30 天历史窗口；全部客户仍由服务端逐客户预测后汇总。
- 本次没有修改 V8、Policy、训练数据、训练截止点、observed state、订单提醒或生命周期异常规则。

### 库存与采购

- 预测、库存/活动采购、人工新增采购保持三个独立接口。库存与采购状态只展示，不参与 A/B 结果筛选。
- 状态接口失败时商品继续展示，但库存和采购显示未知，不伪造 0 库存或未采购，也不开放添加按钮。
- “采购中”继续沿用既有唯一规则：只统计货架补货和智能备货，客户订单自动生成的采购不计入。
- 人工确认后客户端只提交配送商、商品、数量和单位；来源、业务事件、无货架创建和幂等去重全部由服务端负责。
- 新增智能备货专用最小商品规格接口。接口校验商品属于当前配送商，只返回展示所需规格字段，避免 boss-mini 通过通用详情接口读取其他配送商商品。

### 身份边界

- 小程序隐藏非管理员入口；服务端在 Owner 登录上下文存在时再次校验 `nxDiuAdmin == 0`，非管理员返回 `SMART_REPLENISHMENT_ADMIN_REQUIRED`。
- Owner 网关继续校验所有请求中提交的配送商 ID 与登录 Token 的配送商一致。
- 桌面端原请求没有 Owner 上下文，继续使用现有接口和业务口径，不受老板小程序角色判断影响。

## 2026-09-02：修正商品图片来源为空导致的占位图

### 问题现象与根因

- 页面所有常用蔬菜显示相机占位图。该图不是网络加载失败，而是客户端在图片路径为空时主动显示的本地占位图。
- 上一轮只从 `nxDgGoodsFileLarge`、`nxDgGoodsFile` 读取配送商单独上传的图片；圆白菜、黄皮洋葱等商品没有单独上传配送图，真实可用图片保存在 `nxDgNxFatherImg`，旧版参考页面同样使用父类图片。

### 修正内容

- 智能备货最小详情补充 `nxDgNxFatherImg`、平台商品大图和普通图；配送商品查询结果映射显式补充父类图片字段。
- 客户端图片优先级修正为“配送商品大图 → 配送商品普通图 → 平台父类图 → 平台商品大图 → 平台商品普通图 → 本地占位图”。
- 图片仍只用于展示，不参与预测、库存、采购状态或商品排序。

### 回归保护

- 展示测试改用“配送图为空、父类图存在”的真实缺口场景，并增加平台商品图和所有来源为空的用例。
- 页面流程测试锁定最小详情返回父类图后，商品卡片必须生成完整服务器图片地址。
- Server 测试锁定最小详情返回父类图和平台商品图，同时继续拒绝跨配送商商品。

### 本次验证

- boss-mini 智能备货展示、页面合同、页面流程及采购分析图片测试全部通过。
- Server 智能备货最小详情 4 项与采购统计查询合同 5 项通过，Maven 编译成功；其中结果映射静态锁确认父类图片为显式映射。
