# 临时商品与推荐商品接口说明

> 基础路径：`/api/nxdistributergoodslinshi`  
> 请求方式：POST（除特别说明外）  
> Content-Type：`application/json` 或 `application/x-www-form-urlencoded`

---

## 一、业务说明

### 1. 临时商品

临时商品来源于 OCR 识别、粘贴导入等场景，尚未与商品库（nx_goods）建立对应关系。需要人工处理，将其转换为正式商品。

### 2. 推荐商品的作用

当临时商品**不确定对应哪个正式商品**时，可为其添加**推荐商品**（来自商品库 nx_goods）：

- **作用**：将若干候选的 nx_goods 展示给用户，让用户从中选择正确的匹配项，减少盲目搜索
- **场景**：人工在 Vue 页面搜索商品库，将匹配的 nx_goods 加入推荐列表
- **流程**：添加推荐 → 用户选择其一 → 完成转换；若推荐都不对，可申请添加新商品

### 3. 状态说明

| 状态值 | 含义 |
|--------|------|
| 0 | 未处理 |
| 1 | 处理中（有推荐商品，待用户选择） |
| 2 | 申请添加新商品（推荐都不对） |
| -1 | 处理成功 |

## 二、接口列表

### 1. 获取临时商品列表（按状态，3 个 tab）

**路径：** `GET/POST /api/nxdistributergoods/getDisLinshiGoods/{disId}`

**说明：** 返回 `List<NxDistributerGoodsEntity>`，统一格式。支持 3 个 tab：未处理、推荐、申请添加。

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| disId | Integer | 是 | 配送商 ID（路径参数） |
| status | Integer | 否 | 0=未处理，1=推荐，2=申请添加；不传默认 0 |

**返回示例：**

```json
{
  "code": 0,
  "msg": "ok",
  "data": [
    {
      "nxDistributerGoodsId": 100,
      "nxDgGoodsName": "有机西红柿",
      "nxDgGoodsStandardname": "斤",
      "nxGoodsList": [
        {
          "nxGoodsId": 101,
          "nxGoodsName": "有机西红柿",
          "nxGoodsStandardname": "斤"
        }
      ]
    }
  ]
}
```

**字段说明：**

- 所有 tab 均返回 `List<NxDistributerGoodsEntity>`，与原有 `getDisLinshiGoods` 格式一致
- **未处理（status=0）**：临时商品列表，无 `nxGoodsList`
- **推荐（status=1）**：临时商品列表，每项带 `nxGoodsList`（推荐商品列表，来自 nx_goods）
- **申请添加（status=2）**：临时商品列表，若有推荐商品则也展示 `nxGoodsList`

---

### 2. 添加推荐商品（创建/更新 linshi）

**路径：** `POST /api/nxdistributergoodslinshi/addRecommendGoods`

**说明：** 为临时商品添加推荐商品（nx_goods），供用户选择。若该临时商品尚无 linshi 记录则创建，否则更新推荐列表。

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| lsGoodsId | Integer | 是 | 临时商品 ID（nx_distributer_goods_id） |
| nxGoodsIds | String/Array | 是 | 推荐的 nxGoodsId 列表，如 `"101,102,103"` 或 `[101,102,103]` |

**逻辑：**

- 若该临时商品**无** linshi 记录：新建 linshi，`nx_dg_from_nx_dis_goods_id=lsGoodsId`，`nx_dg_goods_ls_status=1`，`nx_dg_recommend_nx_goods_ids="101,102,103"`
- 若**已有** linshi 记录：更新推荐列表并设置 `nx_dg_goods_ls_status=1`

**返回示例：**

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "nxDistributerGoodsLsId": 1,
    "nxDgRecommendNxGoodsIds": "101,102,103",
    "nxDgGoodsLsStatus": 1
  }
}
```

---

### 3. 移除推荐商品

**路径：** `POST /api/nxdistributergoodslinshi/removeRecommendGoods`

**说明：** 从临时商品的推荐列表中移除指定 nxGoodsId。

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| lsGoodsId | Integer | 是 | 临时商品 ID |
| nxGoodsId | Integer | 是 | 要移除的 nxGoodsId |

**逻辑：**

- 从 `nx_dg_recommend_nx_goods_ids` 中移除该 ID
- 若移除后推荐列表为空：将状态改回 0（未处理）或删除 linshi 记录（按业务约定）

**返回示例：**

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "nxDgRecommendNxGoodsIds": "101,103",
    "nxDgGoodsLsStatus": 1
  }
}
```

---

### 4. 申请添加新商品

**路径：** `POST /api/nxdistributergoodslinshi/applyAddNewGoods`

**说明：** 用户表明推荐的都不对，需要申请添加新商品。创建或更新 linshi，状态设为 2。

**参数：** `lsGoodsId`（临时商品 ID）

## 四、前端使用建议

1. **未处理** tab：`getDisLinshiGoods/{disId}?status=0`
2. **推荐** tab：`getDisLinshiGoods/{disId}?status=1`，展示 `nxGoodsList`，用户可点击选择完成转换
3. **申请添加** tab：`getDisLinshiGoods/{disId}?status=2`
4. 添加推荐：在商品库搜索 nx_goods，选中后调用 `addRecommendGoods`（支持 `nxGoodsIds` 数组或 `nxGoodsIdsStr` 逗号分隔）
5. 移除推荐：调用 `removeRecommendGoods`
6. 申请添加新商品：调用 `applyAddNewGoods`
