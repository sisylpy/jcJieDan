# 采购资金总览与统一付款记录

## 入口

Boss 小程序：`采购管理 → 采购资金`。

- 点击采购员可进入该采购员的垫付来源、报销单和付款进度。
- 点击外部供应商可进入该供应商的待结采购、结账单和付款进度。
- 点击“付款记录”或最近付款可进入统一付款列表/准确付款详情。

## 首页数字口径

- 尚未生成报销单：已有正式采购员垫付依据、尚未进入有效报销单的金额。
- 报销单尚未付清：已核定报销单的应报金额减有效付款。
- 尚未生成结账单：已有正式供应商账期依据、尚未进入有效结账单的金额。
- 结账单尚未付清：已核定结账单的应付金额减有效付款。
- 当前待处理金额不受付款日期筛选影响，因此以前月份未付清的款项仍会显示。
- 已登记付款按 `paid_at` 付款业务日期筛选；冲正作为反向事实参与净额，不删除原记录。
- 未归类、金额待核对和供应商争议不冒充确定欠款，单独进入待核对事项。

## 统一付款记录

支持按付款日期、付款用途、收款对象类型及收款对象名称筛选。汇总由服务端按完整筛选范围计算，不随分页变化。

每条记录显示实际收款对象、用途、登记金额、付款日期、方式、来源单据、凭证情况和到账确认状态。付款详情可继续进入原采购员报销单或供应商结账单，并查看采购来源；公司直付采购显示对应资金归类及商品来源。

“已登记付款”仅表示老板端登记了线下付款事实；没有供应商确认依据时不会显示成“对方已到账”。上传凭证不新增付款，凭证作废也不删除付款事实。

## 验收建议

1. 进入采购资金首页，确认采购员待开单/未付与供应商待开单/未付分栏显示。
2. 点击具体采购员或供应商，确认进入同一人的准确明细。
3. 选择付款日期，确认仅付款金额、笔数和最近付款变化，历史欠付仍保留。
4. 打开统一付款记录，分别筛选采购员报销和供应商货款，核对列表总额不因加载下一页变化。
5. 打开一条付款，核对收款人、用途、金额、日期、方式、原单、采购来源和凭证。
6. A 报销付款 60 元、B 供应商付款 80 元时，期间净付款应为 140 元；当前未付分别为 40 元和 120 元。

本页覆盖采购员报销、外部供应商结账和明确的公司直付采购。内部 `offerNx` 协作账单仍沿用原流程，不计入本页全渠道付款总额。
